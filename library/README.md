# KETO Companion 0.1.1

Приватный плагин для личного планирования питания в ChatGPT. Не самостоятельная медицинская система.

Библиотека содержит 78 продуктов USDA, 72 рецептуры и 47 записей научных источников. Дополнительно приведён первоисточник уравнения оценки расхода энергии. Личные данные супруги и ключи доступа в пакет не входят.

## Обычный вход

Выбрать KETO Companion в чате и написать: «Начнём. Помоги настроить питание под меня».

Ассистент проверяет согласие, выбранный Google-аккаунт, доступность выполнения расчётов и необходимые ограничения. Специальные команды не нужны. Google Calendar, Gmail, сохранение фото и контроль веса подключаются отдельно и не обязательны для просмотра рецептов.

## Состав

- `keto-companion`: координация, расчётный модуль, шаблоны и тесты.
- `keto-menu`: справочные данные, меню, замены и покупки.
- `keto-diary`: записи, исправления, чек-листы и обратная связь.
- `keto-settings`: редактирование настроек и откат.
- `keto-export`: выгрузки, фото, голос и действия Google.
- `keto-safety`: ограничения и передача вопроса специалисту.
- `keto-evidence`: научная библиотека и проверка новых утверждений.

Расчёты выполняются на Python 3.10+ со стандартной библиотекой, без отдельного API-ключа. Для тестов разработчика используется pytest. HTML — самостоятельная офлайн-выгрузка, а не встроенное MCP-приложение. Собственный сервер не развёрнут. Действия Google выполняют подключённые приложения с правами текущего пользователя.

Доступность исполнения, приложений и голосового режима проверяется в конкретном аккаунте Plus. Плагин не повышает тариф и не меняет модель автоматически. Без доступного исполнения точные персональные расчёты не выдаются.

## Обновление

Личные вкусы, продукты и рецепты меняются через подтверждённые события. Исходники плагина редактируются отдельно; после изменений нужны тесты, новая версия, упаковка и обновление существующего plugin_id. Личное состояние Google нельзя добавлять в архив плагина или публичный репозиторий.

Медицинская и кухонная валидация не выполнены. Первые 50 поведенческих сценариев из исследовательской библиотеки остаются спецификациями, а не отчётом об их прохождении на Plus.

Граница функций описана в `skills/keto-companion/references/capability-contract.md`; протокол Google — в `references/google-state.md`; запуск вычислений — в `references/runtime.md`.
