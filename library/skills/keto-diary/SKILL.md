# Дневник и обратная связь
Сначала координатор и актуальный Google-state. Пустой день не равен нулевому питанию. Не делай моральной оценки записей и не требуй ежедневного веса.

Явное «запиши...» — намерение сохранить конкретную запись; перед чувствительными/неясными данными коротко покажи, что будет записано. Фраза «что можно приготовить?» не означает, что блюдо съедено. `intake_status`: confirmed / estimated / unquantified. Фото без известной массы обычно unquantified/estimated. Не вписывай расчётную порцию как фактически съеденную без подтверждения.

События через `apply_event`: `diary.add`, `diary.update` (entry_id + changes), `diary.delete` (entry_id), `feedback.add`, `checklist.set`. У каждого действия устойчивый event_id. Повтор после сетевой ошибки использует тот же ID и payload. Чтение→проверка версии→CAS→readback по `../keto-companion/references/google-state.md`. До readback сообщай «подготовлено», не «сохранено».

Обязателен согласованный часовой пояс для «сегодня/вчера»; неизвестную дату уточни. Вес, сон, энергия/голод — по желанию и уместности. Менструальные/медицинские детали не собирай без необходимости и отдельного согласия. Не делай вывод о диагнозе из шкалы энергии. Выраженные симптомы переключают safety workflow немедленно.

`journal_summary(state)` даёт описательную сводку записей, не медицинскую интерпретацию. Сравнивай сопоставимые периоды, указывай количество наблюдений, не обещай потерю жира из разницы веса. Не уменьшай калорийность из-за одного дня/плато и не компенсируй «срыв» голоданием.

Недельный разбор: что понравилось; что неудобно/дорого; какие продукты остались; что изменить в следующем меню. Оценка блюда 1–5 помогает ранжировать вкусы. Не превращай низкую оценку в аллергию. «Сегодня не хочу рыбу» — временный выбор, не постоянный запрет.

Удаление записи удаляет её из активного состояния, но не автоматически из истории Google/старых выгрузок. При запросе полного удаления сначала перечисли принадлежащие пользователю объекты и объясни остаточное хранение провайдером; не обещай абсолютного удаления копий, которые не контролируешь. Общую библиотеку не удаляй.
