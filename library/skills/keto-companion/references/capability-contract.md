# Реальная граница версии 0.1.0
Реализовано в пакете: 7 chat-workflows; stdlib расчётный модуль; персональные настройки/история/откат; дневник/исправления/удаление; отзывы; чек-листы; личные продукты/рецепты; планирование/замены/закупки; импортCSV/JSON; HTML-экспорт; источник-реестр; Google CAS adapter; ICS.

Проверено программно: unit/integration tests модуля на синтетических данных, браузерные операции HTML, реальный Google Docs CAS write/read и отказ stale revision в аккаунте разработчика. Это не клиническая проверка, не тест всей модели Plus и не тест аккаунта супруги.

Инструкциями/коннекторами обеспечивается: выбор Google-аккаунта, сохранение/чтение состояния, экспорт вDrive, действия Calendar/Gmail по подтверждению. Не включено по умолчанию, требует её собственных разрешений. Права подключения платформой не расширяются.

Не реализовано: отдельный облачный backend/MCP с собственным OAuth, встроенный MCP UI/навигационная вкладка ChatGPT, независимый серверный контроль каждого ответа, автономный scheduler, push-приложение, автоматическая двухсторонняя синхронизация офлайнHTML, клиническая валидация, все фотографии блюд, автоматическое обновление медицинских правил/каталога, ротация2МБ state. Не изображать эти функции существующими.

Запуск на Plus требует фактической доступности плагинов, подключений и вычислительной среды. Voice/Live/фото — возможности хоста, не новый собственный голосовой движок. Установка в аккаунт разработчика не устанавливает плагин супруге. Перенос: доступное приватное sharing либо импорт того же ZIP в её аккаунт; без health-state/ключей.

Готовность к персональному использованию: сама пользовательница согласилась; Google владельца проверен; runtime self-check прошёл именно в её чате; write/readback с несекретной отметкой прошёл; новое окно чата нашло ту же отметку; дата/зона проверены; личная анкета не содержит неизвестных критичных полей; пример меню принят после проверки. До этого статус «требуется личная активация», а не «всё подключено».
