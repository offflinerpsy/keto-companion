# Исполнение, а не арифметика из текста
Пакет содержит полный исходный stdlib Python runtime; отдельный API-ключ не нужен. Нужны Python 3.10+ и доступная среда исполнения в текущем ChatGPT/Work. Наличие skills не доказывает наличие исполнения в конкретном чате.

Загрузи пакет по фактическому пути, предоставленному средой установки. Не выдумывай путь и не обходи личную файловую систему в поисках. Поддерживаемые файлы перечислены в `runtime_manifest.json`. Если файлы доступны только как ресурсы навыка, используй поддерживаемую выдачу/материализацию этих ресурсов или приложенный пользователем runtime ZIP, а не пересоздавай весь модуль по памяти. Перед выполнением проверь SHA-256 файлов навыков, данных и исполняемого модуля против runtime_manifest.json (метаданные plugin.json/.codex-plugin нормализуются платформой и в этот runtime-манифест не входят) и запусти `scripts/self_check.py`. После этого импортируй `scripts/keto_core.py`. Данные лежат в `../../keto-menu/data` относительно scripts по логике load_catalog.

Если среда не может прочитать/исполнить неизменённые файлы, точный персональный planner недоступен: объясни один конкретный шаг восстановления (поддерживаемый чат с анализом файлов/прикрепление выданного runtime ZIP), сохрани общение и образовательные ответы, не подменяй код устным расчётом. Не заставляй обычного пользователя устанавливать Python. На новом устройстве/тарифе проведи smoke-test, прежде чем обещать расчётные функции.

Функции: load_catalog, merge_personal_catalog, screen_profile, validate_baseline, estimate_energy, validate_targets, calculate_recipe, find_recipes, suggest_plan, replace_plan_meal, build_plan, approve_plan, shopping_list, review_label, validate_custom_food, validate_custom_recipe, new_state, apply_event, journal_summary, export_plan_csv, import_plan_csv, import_plan_json, document_write_request, make_ics, quote_shopping. Подробные сигнатуры в исходном модуле. Вход/выход — JSON-совместимые данные, не eval/exec пользовательского текста.

Никакие credentials, OAuth tokens, сетевые запросы или удалённые файлы этим модулем не исполняются. Google-действия выполняет авторизованный коннектор. CAS защищает записи от конфликтов; это не серверная гарантия того, что языковая модель никогда не пропустит вызов. Production-усиление требует отдельного OAuth MCP-сервера, который пока не развёрнут. HTML-экспорт не является этим сервером.
