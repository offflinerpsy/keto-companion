# KETO Companion · внутренний пилот

Вход Google через Firebase реализован для пилота по приглашению, привязанному к адресу почты; реальный вход ещё не проверен. Приглашение принимается отдельно после входа. Запрашиваются только `openid`, `email`, `profile`; Gmail, Drive и Calendar не подключаются автоматически.

При настроенном сервисе доступны общение, проверяемые рецепты, дневник, черновик меню и список покупок. Персональное меню требует подтверждённого совершеннолетия, ответов об ограничениях и отдельно согласованных ориентиров. Изменения показываются для подтверждения. Помощник не врач и не служба экстренной помощи.

Личный источник можно добавить ссылкой, короткой цитатой или файлом. Ссылка Instagram сама не загружает публикацию. После явного выбора источник обсуждается как недоверенный материал; личный рецепт создаётся только после ручного ввода сопоставленных ингредиентов, проверки и отдельного подтверждения. Общий каталог из источника автоматически не изменяется.

В настройках можно запросить удаление. Сеансы отключаются сразу, затем очистка продолжается по отдельному коду; до подтверждения статус остаётся «ожидание». Резервные копии могут удаляться отдельно. Этот пакет ещё не развёрнут и не прошёл проверку реальных аккаунтов, клиническую и визуальную приёмку; реальные личные данные до них использовать нельзя.
