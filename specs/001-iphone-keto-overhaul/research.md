# Decisions and evidence

- iOS familiarity: native system font stack, semantic spacing/type/controls and clear selected state; open icons with notices. Apple HIG https://developer.apple.com/design/human-interface-guidelines/typography ; resource terms https://developer.apple.com/support/downloads/terms/apple-design-resources/Apple-Design-Resources-License-20230621-English.pdf ; Lucide license https://github.com/lucide-icons/lucide/blob/main/LICENSE . Do not bundle restricted Applefonts or assume download means web-redistribution rights.
- Target: official physical display1320x2868 https://support.apple.com/en-us/125091 .440x956 logical reference is provisional; actual Safari safe areas/keyboard must be measured on device.
- Foods:85 current local records,72 recipes. Internal F IDs identify USDA records, not GI. Existing UI/server caps and missing aliases are separate from true data coverage. USDA downloads CC0/keyless https://fdc.nal.usda.gov/download-datasets/ ; live API needs key https://fdc.nal.usda.gov/api-guide/ . No newkey assumed.
- OpenFoodFacts: https://openfoodfacts.github.io/openfoodfacts-server/api/ ; reuse https://support.openfoodfacts.org/help/en-gb/12-api-data-reuse/94-are-there-conditions-to-use-the-api . Attribution/ODbL and shared-IP15 product/min,10 search/min require explicit search, caching, field bounds and honest errors. Keep source separation; no silent bulk merged catalog.
- GI:2021 international tables https://doi.org/10.1093/ajcn/nqab233 do not establish unrestricted data redistribution.2008 https://pmc.ncbi.nlm.nih.gov/articles/PMC2584181/ has NC/ND constraints. Small exact-preparation CC BY4.0 study examples exist https://pmc.ncbi.nlm.nih.gov/articles/PMC11720369/ ; conflicting rows excluded. No verified universal licensed GI catalog; never infer GI or copy an unlicensed aggregate. Measured examples are not universal values for a different branded/prepared food.
- Nutrition: data/carbohydrate basis/fiber unknowns, measured glucose/ketones and physical/model validation remain explicit. Existing safety/clinical constraints are not relaxed for convenience.
