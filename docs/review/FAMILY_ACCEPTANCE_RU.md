# Перед передачей супруге: приёмка на её устройстве

Это оставшиеся проверки, а не обещание полного медицинского сопровождения. Основные программные ошибки ревью устранены; проверка на реальном аккаунте и устройстве не подменяется тестовыми данными.

**Первый отдельный шаг:** открыть профиль в обычном аккаунте и проверить, что все известные аллергии/ограничения указаны верно. Изменить только имя или другой нейтральный параметр, посмотреть карточку подтверждения и убедиться, что список ограничений не изменился. Исправление предотвращает новое удаление; оно не восстанавливает неизвестные прошлые значения автоматически.

После первого шага проверяются по одному: согласие и раздельный доступ членов семьи; справочное блюдо против персонального меню; запись еды без граммовок не показывает точный остаток; две порции дают покупки на всё блюдо, но личный дневник — на выбранную долю; отказ от сохранения действительно оставляет состояние неизменным; диктовка остаётся черновиком; PDF передаётся только через явное «Поделиться»; импортированный Календарь уведомляет по разрешённым настройкам телефона.

Реальные диагнозы, лекарства и измерения не нужно отправлять в GitHub или разработчику: пользователь вводит их только в своём пространстве с согласия. При медицинских ограничениях оценку допустимости кето и индивидуальных ориентиров делает специалист, не автоматический тест.

Открытый технический блокер: GitHub Actions не создаёт jobs. Полный workflow должен действительно выполниться после устранения ограничения запуска. До этого нет зелёного CI и нет безусловной отметки «готово для повседневного использования».
