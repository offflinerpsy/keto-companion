## Продукт простыми словами

Вход — по Google/Firebase и приглашению на ту же почту.
Аутентификация сама по себе ещё не даёт членство; членство не заменяет согласие на личные данные.
Пользователь сам подтверждает обработку Azure, сохранение и наличие сведений о здоровье.
Админ управляет приглашениями/статусами и видит метаданные использования, но не медицинский дневник семьи.
Legacy Entra/plugin остаётся отдельным контуром; автоматического переноса личного состояния нет.

Знакомство состоит из согласия, исходных данных, ограничений и ориентиров.
Неотвеченные вопросы остаются неизвестными.
Сервер рассчитывает предварительную оценку и объясняет допущения.
Preview, сохранение ориентиров и выбор меню — разные действия с подтверждением.
Вне области пилота доступны объяснение ограничения и справочные рецепты.

Кухня предлагает три режима: только свои продукты, можно докупить, идеи без обязательной кладовой.
Есть семь вариантов оборудования и 18 разрешённых способов.
Модель выбирает известные продукты/граммы/метод, сервер считает нутриенты и добавляет инструкции.
Оригинальная генерация и fallback-шаблоны имеют разные честные подписи.
Ни одна карточка не означает, что блюдо испытано на кухне или одобрено врачом.

Дневник может содержать свободную заметку без граммовок.
Половина порции отличается от половины всего блюда.
Общие итоги считают только известные подтверждённые количества и отдельно отмечают неполные записи.
Просмотр/сохранение рецепта автоматически не списывает кладовую.

Память — подтверждённые факты плюс ограниченная история и собственные цитаты.
До 12 тем, до 60 сообщений в теме, до 200 КБ общей истории.
В старый контекст берутся максимум пять цитат по 500 символов.
Удаление темы не удаляет общий профиль/предпочтения; забывание факта — отдельное подтверждение.

Диктовка создаёт редактируемый текст; пользователь отправляет его сам.
Фото не устанавливает точную массу, масло или аллергены.
Собственные источники требуют прав; ссылка без текста остаётся needs_content и не считается прочитанной.
PDF готовится отдельно от клика «Поделиться»; это системный обмен, не подтверждённая отправка в Telegram.
Напоминания выгружаются в ICS; фонового push и автоматического обновления календаря нет.

## Контуры исполнения и версии

| Контур | Назначение | Граница |
| --- | --- | --- |
| Cloudflare Worker/static | Web UI, членство, сессии, API | Свой пользователь и CSRF |
| D1 | Identity/invites/jobs и личный JSON | Не публичный файл |
| Private R2 | Загруженные собственные источники | Только owner-prefix и авторизованный доступ |

| Sol high | Разрешённые рецептурные IDs/граммы | 3500–5000 output tokens; серверная перепроверка |
| Transcription | Короткое аудио → текст | До 60 секунд/1 МБ; не голосовой разговор |
| Legacy Entra/plugin | Существующий отдельный Azure/ChatGPT клиент | Другие идентичности/хранилище/подтверждения |
