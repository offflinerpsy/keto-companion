# Безопасность и границы

Приватный GitHub — хранилище исходников, не личных медицинских данных. В репозиторий запрещены `.private`, ключи, токены, cookies, `.env`, локальные базы, необработанные логи агентов и пользовательские дневники. Публичные Firebase browser identifiers не являются сервисными секретами; серверный секрет, приватный ключ и OAuth client secret туда не относятся.

Доступ администратора ограничен членством, приглашениями и счётчиками. Личные записи остаются доступны их владельцу. Согласие семьи или разработчика не заменяет согласие конкретного пользователя. Персональные планы разрешаются только после анкеты и ограничений исходного движка; неизвестные сведения не считаются отрицательными ответами.

Ссылки и загружаемые рецепты недоверенные. Закрытый Instagram не обходится через пароль, cookies или неофициальный API. Источник не меняет инструкции, клинические правила или общую базу. Изображения требуют ограничений размера и очистки метаданных до постоянного хранения.

Подтверждение на стороне UI опирается на корректный клиент и не является криптографическим доказательством человеческого нажатия. Проверки модели, тесты безопасности и клиническая оценка различаются. Ни набор тестов, ни высокий номер модели не дают гарантии безошибочности.

Удаление возобновляемое: сначала блокируются сеансы, затем очищаются записи и объекты. Незавершённая загрузка может оставить удаление ожидающим сверки. Удаление приложения не удаляет Google-аккаунт. Сроки резервных копий, служебных записей и бюджет должны быть проверены до публичной коммерческой эксплуатации. Сертификация HIPAA/GDPR не заявляется.

Сообщайте об ошибках в приватной Issue, не публикуя личные данные и секреты. CI не получает облачных секретов и не развёртывает приложение автоматически.
