# KETO 0.7.1 — дизайн, изображения и разработка

Приложение: https://keto-companion-saas-staging.offflinerpsy.workers.dev/ . Это закрытый семейный пилот, не открытый каталог и не медицинская служба.

## Навигация и повседневные действия

Здесь описан реализованный в исходниках интерфейс C10–C13. Фактически развёрнутую версию и приёмку C14 проверяйте в [CURRENT_STATUS.json](../CURRENT_STATUS.json): инструкция не подтверждает завершение выпуска. [Согласованный продуктовый план](../design/PRODUCT_DELIVERY_2026_11_09.md) заменяет прежнее визуальное направление.

Внизу четыре раздела: **Чат / Дневник / Рецепты / Продукты**. **Профиль и настройки** открываются кнопкой вверху, **Моё меню** — внутри Рецептов. Используются системный шрифт, обычный основной текст 17px, нейтральные поверхности и синий акцент. Крупный текст и тёмная тема сохранены как отдельные настройки.

Для рецептов, своих блюд и продуктов действует один путь: **Записать съеденное → количество и основа → дата/время еды → Проверить запись → Добавить в дневник**. После подтверждения открываются Дневник, сохранённая запись и итоги выбранного дня. **Исправить** меняет эту запись, **Повторить** готовит новую для подтверждения. Сохранение рецепта, планирование еды и пополнение запасов остаются отдельными действиями. Неизвестные нутриенты остаются неизвестными.

В Продуктах сначала выберите поиск по названию, сканирование штрихкода, ввод штрихкода, фото этикетки или ручной ввод. Затем проверьте найденное и недостающие сведения, подтвердите сохранение и выберите дальнейшее действие. Камера для штрихкода и чтение фото этикетки — разные способы. Действия под ответами в Чате открывают соответствующий сценарий. Ожидающие подтверждения доступны вверху: закрытие окна проверки оставляет изменение ожидающим, **Отмена** отменяет его.

## Изображение прямо в чате

Можно вставить скопированную картинку, перетащить файл на чат или выбрать фото обычной кнопкой. До отправки появляется предпросмотр и удаление. Текст не обязателен, если уже подготовлена картинка; отправка остаётся вашим действием. На одном сообщении поддерживается одно изображение. Само наличие изображения не позволяет установить точные граммы и нутриенты.

Для прямой ссылки на картинку есть отдельная кнопка. Публикация Instagram, веб-страница и прямая ссылка на изображение — не одно и то же. В пилоте разрешены только images.unsplash.com, images.pexels.com и upload.wikimedia.org. До явной загрузки ссылка не запрашивается. Для остальных источников передайте разрешённый файл или скриншот. Закрытый Instagram/Telegram не читается через ваш сеанс в другом приложении.

## Разработка: только владельцу

В чате владелец может выбрать «Разработка» вместо «Питание» либо открыть «Профиль → Разработка · только владелец». С прикреплённым фото/личным источником вход в технический режим запрещён; содержимое дневника не переносится в запрос программисту.

Нажмите «Включить на 1 час», напишите короткое **техническое** пожелание и подтвердите, что оно не содержит личных данных. Затем «Подготовить точный текст» показывает задачу. Отдельное подтверждение разрешает один вызов Sol high. Не отправляйте туда диагнозы, пароли или фрагменты закрытых переписок: поле не является автоматическим фильтром персональных данных.

После получения изменений есть отдельная кнопка проверки в изолированной среде Cloudflare. Только при успешной проверке появятся приватный предпросмотр и проверенный diff. Разрешено менять три файла интерфейса: app.css, help.html и developer-extension.js. Нельзя менять сервер, питание, аллергены, авторизацию, тесты или зависимости. Лимит — три генерации в сутки, одна активная задача. «Выключить / остановить» отменяет работу и запрещает принятие позднего результата.

**Проверено — не значит опубликовано.** Автоматической кнопки изменения общего семейного сайта нет. Проверенный diff передаётся в отдельный обычный выпуск через GitHub и Cloudflare. Это сознательно ограниченный пилот, не произвольный Codex с ключами рабочей базы.

## Проверки и границы

Полный набор проверок исходников работает в Cloudflare Builds; проверка предложенного кода — в отдельном Cloudflare Container без интернета, личных данных и ключей. GitHub хранит код/историю, но GitHub Actions больше не требуется для этого конвейера.

Актуальные результаты и хэши указаны в [текущем статусе](../CURRENT_STATUS.json). [Отчёт о предыдущем выпуске](../evidence/CF_DEV_MEDIA_08_RELEASE_RECEIPT.json) сохранён как история. Реальные вход/подтверждение владельца и физический iPhone остаются отдельной пользовательской приёмкой; браузерные тесты её не подменяют.
