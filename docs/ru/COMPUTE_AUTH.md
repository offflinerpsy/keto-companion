# Связь Cloudflare с Azure

Worker подписывает метод, путь, время, одноразовый идентификатор и хеш тела запроса отдельным ключом Ed25519, который хранится только в секретном binding Cloudflare. В Azure передаётся лишь открытый проверочный ключ. Сервер проверяет подпись, свежесть, допустимую операцию и защиту от повтора; расчёт выполняется в памяти. HMAC сохранён как отдельный несовместимый одновременно режим для прежних тестов, а не как выбираемое клиентом ослабление защиты. Личное состояние возвращается в D1; Azure сохраняет только хеш одноразового идентификатора и срок его действия.

Закрытый ключ не выводится, не записывается в GitHub и не передаётся браузеру. Тесты используют отдельные временные ключи. Тестовый сеанс в staging не заменяет настоящий вход человека через Google.
