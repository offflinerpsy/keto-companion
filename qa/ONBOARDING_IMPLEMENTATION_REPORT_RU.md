# KETO-ONBOARDING-05 — результат исходной фазы

В существующей ветке ux/guided-onboarding реализован 0.5.0-guided-pilot: четыре возобновляемых этапа знакомства для участника и администратора, видимая страница ориентиров, крупные числовые контролы, настоящий noUiSlider для веса и энергии, Back/Forward и прямые пути к рецептам. Предпросмотр, сохранение исходных данных и замена ориентиров разделены явными подтверждениями. Ручные цели и остальные функции приложения сохранены.

Серверная политика starter-v1 повторно использует keto_core.estimate_energy/validate_baseline и прежние клинические проверки. Предпросмотр объясняет формулу, коэффициенты и продуктовые допущения; модель и браузер не назначают канонические числа. Изменения медицинских исходных данных/цели/режима делают рассчитанные ориентиры устаревшими; имя и оформление — нет. База знаний содержит авторские краткие объяснения и ссылки из существующего корпуса, новые источники — отдельно. Отозванная S18 исключена из оснований; исходный корпус и поставленный noUiSlider не изменены.

Один финальный полный прогон: **420 Python passed, 1 skipped; 81 Node passed**. Прежние UI/OAuth проверки без браузера также прошли. Пропущен Linux-only тест RAM-дескриптора для non-fragmented MP4. Есть одно предупреждение pytest о record_property/JUnit xunit2; запись результатов двух профилей в XML присутствует, тест не упал. Репозиторная проверка хешей/содержимого и git diff --check прошли. Логи: qa/onboarding-final-python.log, qa/onboarding-final-node.log, qa/onboarding-final-legacy-ui.log, qa/onboarding-final-repository.json.

**Ограничение меню:** для обоих синтетических здоровых профилей с автоматически рассчитанными, а не вручную заданными целями эвристический поиск не нашёл меню в текущем каталоге. Приложение показывает реальные ограничения и путь к справочным рецептам/индивидуальному плану; белок, клетчатка и аллергии не ослаблялись. Это не доказательство математической невозможности, но требующий оценки родителем предел покрытия каталога. Автоматические ориентиры не следует объявлять проверенным готовым меню.
