# KETO Companion 0.2.1 · приватный облачный пилот

Тот же персональный плагин, теперь с Azure-сервисом, собственным OAuth/PKCE и интерактивным MCP-ресурсом. Имя и аудитория не менялись. Отдельный deployment GPT-6.1 Terra разбирает запросы; арифметику и запись выполняет программа. Медицинское наблюдение не предоставляется.

## Первый запуск
Установите/обновите плагин в разрешённом аккаунте и пройдите штатное подключение. Microsoft-аккаунт должен быть приглашён в существующий tenant и внесён в разрешённые пользователи сервиса. Супруга использует собственную личность, не тестовый аккаунт создателя. Затем отдельно выбирает согласие на Azure-обработку/хранение и заполняет нужные ограничения. Проверка настоящей установки на её Plus/телефоне ещё нужна.

Фраза для старта: «Объясни, как это работает, и помоги познакомиться — по два-три вопроса за раз». Оформление можно менять словами: «крупнее текст», «тёмная тема», «убери калории». Изменение сначала показывается и подтверждается. Новые медицинские сведения не обходят ограничения ради удобства.

## Данные и границы
Личные данные: приватный Azure Blob, не память чата и не второй Google-профиль. Библиотека данных 0.1.1 сохранена: 78 продуктов / 72 рецептуры / 47 источников. Нет готовых фотографий всех блюд, самостоятельного голосового движка, автоматической Gmail/Calendar-синхронизации, медицинских назначений и гарантии безошибочности.
