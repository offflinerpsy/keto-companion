# Изменения

## 0.2.1 — 7 ноября 2026
- Подключение к существующему Azure HTTP/MCP-сервису и отдельному GPT-6.1 Terra.
- Интерактивный ресурс, cloud-first профиль и версионные подтверждаемые изменения.
- OAuth/PKCE, ограниченные токены, ротация/отзыв; вход сайта Microsoft Entra отдельно.
- Исправления зависших запросов, ограничений, устаревшего меню и смены пользователя.
- Русские подписи, перенос уведомлений/навигации, явные карточки подтверждения.
- Google-путь больше не второй источник личного состояния; отдельно запрошенные экспорты.
- Исходная научная библиотека 0.1.1 не переименована в клинически проверенную.
- Локальные/протокольные тесты не означают проверку реального Plus/голоса супруги.
