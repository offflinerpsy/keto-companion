# Google в облачной версии 0.2.1

Канонический профиль и дневник находятся в авторизованном Azure-сервисе. В версии 0.1.x применялся Google Docs CAS; этот путь больше не используется параллельно для записи одного профиля. Не создавай новую Google-копию как второй источник истины.

Google Drive/Docs/Sheets применяются для отдельно запрошенной выгрузки и материалов. Выбери фактический аккаунт и папку, получи рассчитанные данные `keto_export`, выполни авторизованный коннектор, проверь запись и только затем сообщи ссылку. Экспорт содержит выбранный объём; медицинскую историю не включай автоматически. Владелец выбирает аудиторию. Не делай публичные ссылки и не отправляй супругу без её согласия.

Gmail/Calendar требуют собственных подключений и конкретного запроса. Отсутствие Google не должно блокировать облачный дневник. Настройка reminders_enabled сама по себе ничего не планирует. Импорт назад означает проверяемое предложение, а не бесконтрольную синхронизацию.
