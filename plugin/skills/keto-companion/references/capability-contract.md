# Реальная граница версии 0.2.1

## Реализовано
Azure HTTP/MCP-сервис, отдельный Azure GPT-6.1 Terra для разбора сообщений, программные расчёты, профиль/дневник/история/предложения в приватном Blob, подтверждаемые изменения и отзыв согласия, личный JSON-экспорт, импорт меню CSV/JSON, рассчитанные рецепты и меню, UI-настройки и откат, интерактивный ресурс приложения. Entra-вход сайта и отдельный OAuth/PKCE-поток плагина; проверка приглашённого субъекта, ротация и отзыв токенов. Фото принимается как JPEG/PNG, нормализуется перед передачей модели; точные граммы из вида не выводятся.

## Не обещать
Автоматическую установку супруге, уже пройденный ею OAuth, клиническую безопасность, отсутствие ошибок модели, полный анализ всех нутриентов, кухонную проверку всех блюд, автоматическую двустороннюю Google-синхронизацию, чтение Gmail без запроса, фоновое медицинское наблюдение, самостоятельный календарный график анализов, собственный нативный голос Terra, произвольную самоперепись кода. Фото всех 72 блюд не созданы. Тариф Plus не повышается плагином.

## Границы тестов
Программные тесты на синтетических данных, DOM-модель без браузера, протокольные проверки HTTP/MCP и реальный запрос Azure могут подтверждать конкретную реализацию. Они НЕ подтверждают реальную установку/авторизацию/голос в аккаунте супруги, визуальную доступность после обновления, клиническую пригодность. Не суммируй старые браузерные проверки с новыми как один свежий сквозной тест. Публичный health endpoint — не доказательство защищённого MCP-сеанса.

## Данные и версии
Научная и пищевая библиотека 0.1.1: 78 продуктов, 72 рецептуры, 47 записей источников. Это отдельная версия данных, не версия облачного сервиса. Плагин/сервис 0.2.1 используют её без утверждения о новом научном пересмотре. Старый Google-документ не становится вторым каноническим профилем. Перенос данных — только явная согласованная миграция, не молчаливое объединение.

## Запуск для человека
Нужны приглашённый личный Microsoft-аккаунт, её авторизация подключения и согласие на обработку/хранение, проверка зоны/анкеты/лекарств/аллергий, согласованные пищевые ориентиры. Аккаунт разработчика сейчас может быть тестовым `demo` — не использовать его для супруги. Согласие разработчика на синтетические тесты не означает согласия супруги.

OAuth access действует до часа, refresh — до семи дней; не более 16 ротаций на семейство, затем повторное подключение. Ограничители запросов не являются гарантированным финансовым бюджетом. Нативная изоляция app-only инструментов опирается на корректное поведение хоста; серверный UI-marker не является криптографическим доказательством нажатия человеком.
